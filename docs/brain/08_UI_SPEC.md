# Kalka Co. — UI/UX Specification

## Direction
Premium, editorial, corporate, sophisticated, strategic and human.

## Avoid
Generic SaaS styling, excessive gradients/glassmorphism, giant rounded cards, excessive shadows, random decorative blobs, over-animation and template-like repetition.

## Core Components
Navbar, MobileMenu, Footer, Hero, SectionHeader, Button, Cards, Forms, Modal, Drawer, Accordion, Tabs, Toast, Skeleton, EmptyState, ErrorState, Breadcrumbs, LogoCloud, Gallery, Search, FilterBar, CTA.

## Interaction
Sticky navbar with scroll state; animated mobile navigation; accessible dropdowns; subtle hover states; scroll reveal; reduced-motion support; no animation blocking content.

## Responsive
Intentional layouts for 320, 375, 390, 430, 768, 1024, 1280, 1440 and 1920+ widths.

## Homepage Flow
Navigation → Hero → Trust → About → Services → Why Kalka → Industries → Approach → Selected Work → Media → Awards → Insights → Team → CTA → Footer.

## Accessibility
Semantic HTML, keyboard navigation, visible focus, proper labels, contrast, reduced motion, accessible dialogs/menus.

## Design-System Route
Development-only `/design-system` must demonstrate primitives and interaction states before Phase 2.\n
