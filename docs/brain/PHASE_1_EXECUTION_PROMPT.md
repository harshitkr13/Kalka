Create development-only `/design-system` showcase demonstrating components and interactive states.

## Design
Premium, editorial, corporate, strategic and sophisticated. Original Kalka identity. Do not copy reference websites. Avoid generic SaaS/AI-template styling, excessive gradients/glassmorphism, giant rounded cards, excessive shadows and unnecessary animation.

## Strictly forbidden in Phase 1
- MongoDB
- Express APIs
- Google OAuth
- OAuth secrets
- MongoDB URI
- JWT/session secrets
- Cloudinary
- Email API
- GA4/Search Console integrations

No external credentials are required.

## QA
Run project lint, typecheck and production build. Visually inspect desktop/tablet/mobile. Check keyboard navigation, focus states, reduced motion, hydration/console errors and overflow.

## Acceptance
Phase 1 is complete only when the design system is coherent, responsive, accessible, interactive and build-clean.
