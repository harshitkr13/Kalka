# Kalka Co. — Decisions

- **D001 — Next.js**: Chosen for SEO, performance and content-heavy public pages.
- **D002 — Express Backend**: Chosen to preserve the requested MERN-style architecture and provide a clear API boundary.
- **D003 — MongoDB**: Chosen for flexible CMS-oriented documents.
- **D004 — Google OAuth**: Mandatory for admin authentication.
- **D005 — RBAC**: Backend-enforced roles provide least-privilege access.
- **D006 — Cloud Media**: Use Cloudinary/object storage rather than MongoDB binaries.
- **D007 — Separate Content Types**: Blog, News, Press Release, Media Mention and Case Study are distinct.
- **D008 — No AdMob**: Not relevant to this website.
- **D009 — Phase-Gated Credentials**: Request credentials only when the active phase needs them.
- **D010 — Original Design**: Reference agencies inform functional maturity, not copied visual design.\n
