# Kalka Co. — Data Sources & Content Rules

## Source Hierarchy
1. Kalka Co. approved content
2. Approved CMS content
3. Approved brand assets
4. Verified external publication links
5. Development placeholders

Never invent business claims, clients, awards, coverage, people, offices, testimonials, metrics or results.

External media should link to the original publication. Do not republish full copyrighted articles.

Images must be licensed/approved. Development placeholders must be clearly replaceable.\n
