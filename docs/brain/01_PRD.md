# Kalka Co. — Product Requirements Document

## Product
Kalka Co. Media Consultancy website + CMS/admin platform.
Tagline: **Strategic Communication. Lasting Impact.**

## Goals
- Establish premium credibility.
- Generate qualified business enquiries.
- Showcase services, industries, clients, campaigns and case studies.
- Build thought leadership.
- Showcase media mentions and awards.
- Support careers/recruitment.
- Let non-technical staff manage content.

## Audience
Real Estate, Infrastructure, Corporate Organizations, Startups, Hospitality, Education, Retail, Healthcare, Public Affairs and Professional Services.

## Public Pages
Home, About, Team/Leadership, Services, Service Detail, Industries, Industry Detail, Our Work, Case Studies, Case Study Detail, Clients, Insights, Article Detail, News, Media Mentions, Awards, Media Gallery, Careers, Job Detail, Contact, Privacy/Terms/Cookie pages as applicable.

## Core Services
Public Relations; Media Relations; Corporate Communications; Reputation Management; Thought Leadership; Content Development; Crisis Communications; Brand Positioning; Digital Communications.

## Major Features
Premium responsive UI; CMS/admin; Google OAuth admin authentication; RBAC; blog/news; case studies; clients; team; awards; media gallery; media mentions; careers; lead management; contact forms; WhatsApp; email notifications; SEO; GA4/Search Console; search/filtering; analytics events.

## Homepage
Navigation → Hero → Trust/client logos → About → Services → Why Kalka → Industries → Approach → Selected Work → Media Coverage → Awards → Insights → Team → CTA → Footer.

## Lead Lifecycle
NEW → CONTACTED → QUALIFIED → PROPOSAL → WON/LOST → CLOSED.

## Content Integrity
Never invent clients, awards, media coverage, people, offices, testimonials, statistics or results. Use clearly marked placeholders until approved content is supplied.

A feature is complete only when its UI, responsive behavior, validation, error/loading/empty states, security, tests and documentation are addressed.\n
